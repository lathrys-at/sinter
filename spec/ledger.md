# Sinter specification: approval-ledger format

This document will define the approval-ledger format. The ledger is an
append-only record of human judgments — approvals, declines, and plan
deaths — stored on a dedicated git ref. The document will define the
entry kinds and their fields.

The specification is not written yet. The source material is in
[docs/design-notes.md](../docs/design-notes.md), sections 6.4 ("Cash-Out:
Specifications & the Approval Ledger") and 13.7 ("Ledger entries").
