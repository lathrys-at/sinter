# Sinter specification: doctag vocabulary

This document will define the doctag vocabulary. Doctags are tags such as
`@req` and `@satisfies` that Sinter reads in code comments and in
markdown. The document will define the grammar of a tag, the meaning of
each tag, and the rules for targets and revisions.

The specification is not written yet. The source material is in
[docs/design-notes.md](../docs/design-notes.md), section 3 ("The Graph").
This file is a placeholder. It exists so that the specification has a
stable path and a clear license from the start.
