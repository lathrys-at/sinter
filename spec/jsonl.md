# Sinter specification: JSON Lines interchange schema

This document will define the JSON Lines (JSONL) interchange schema.
Sinter emits its facts — nodes, edges, evidence, findings — as JSONL so
that other tools can read them. The document will define the canonical
form, the envelope, and each record type.

The specification is not written yet. The source material is in
[docs/design-notes.md](../docs/design-notes.md), section 13 ("JSONL
Interchange").
